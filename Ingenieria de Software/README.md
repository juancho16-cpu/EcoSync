# Ingeniería de Software – EcoSync

Acá van los documentos de Ingeniería de Software de cada entrega:

- 1ra entrega: metodología, relevamiento, requerimientos (IEEE 830), MER y pasaje a tablas.
- 2da entrega: puntos de función, factibilidades, costo-beneficio, Gantt, diagramas de clases, casos de uso y paquetes.
- 3ra entrega: plan de testing, caja blanca y caja negra, casos de prueba, manuales de uso, instalación y administración.

Los tests automáticos del sistema están en `Programacion/sigeru-api-*/tests/`.
